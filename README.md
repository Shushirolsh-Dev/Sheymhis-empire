# Sheymhi's Empire — Nails & Lash Studio

A responsive, editorial-style beauty studio website built with Next.js, TypeScript and Tailwind CSS. Appointment requests open WhatsApp with the customer's booking details prefilled.

## Run locally

```bash
npm install
npm run dev
```
